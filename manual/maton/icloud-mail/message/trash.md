{% raw %}## maton icloud-mail message trash

```
maton icloud-mail message trash <message-id> [flags]
```

Move a message to the Trash folder. It isn't deleted: "message untrash" moves it back, until the provider empties Trash. A message's ID names its folder, so moving it changes the ID; the new one is printed.
