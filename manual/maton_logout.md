{% raw %}## maton logout

```
maton logout [flags]
```

Logout of your Maton account from the CLI.

### Options


<dl class="flags">
	<dt><code>-a</code>, 
		<code>--all</code></dt>
	<dd>Clear credentials for all profiles you are currently logged into.</dd>
</dl>


### Options inherited from parent commands


<dl class="flags">
	<dt><code>-p</code>, 
		<code>--profile &lt;string&gt;</code></dt>
	<dd>Profile to use for this invocation (overrides the active profile; also reads MATON_PROFILE)</dd>
</dl>
