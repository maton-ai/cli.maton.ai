{% raw %}## maton alias

Aliases can be used to make shortcuts for maton commands or to compose multiple commands.

Run `maton help alias set` to learn more.


### Available commands

* [maton alias delete](./maton_alias_delete)
* [maton alias import](./maton_alias_import)
* [maton alias list](./maton_alias_list)
* [maton alias set](./maton_alias_set)


### Options inherited from parent commands


<dl class="flags">
	<dt><code>-p</code>, 
		<code>--profile &lt;string&gt;</code></dt>
	<dd>Profile to use for this invocation (overrides the active profile; also reads MATON_PROFILE)</dd>
</dl>
